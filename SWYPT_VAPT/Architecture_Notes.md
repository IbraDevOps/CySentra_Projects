# Initial Architecture Notes

## Current Understanding

Frontend:
- Next.js / React application

Backend:
- Node.js / Express APIs

Infrastructure:
- Ubuntu Linux server
- Apache reverse proxy
- Publicly exposed API services

Known Open Ports:
- 22 (SSH)
- 80 (HTTP)
- 443 (HTTPS)
- 3005
- 3017

Blockchain Components:
- Solidity contracts
- Rust ICP canisters
- Web3 integrations

Payment Systems:
- M-Pesa
- Crypto wallet/payment systems

Potential Databases:
- MongoDB (suspected)
- Redis (possible)

Potential Risks:
- API authorization flaws
- BOLA/IDOR
- Privilege escalation
- JWT weaknesses
- Business logic abuse
- Wallet impersonation
- Admin exposure
