# CySentra:Cyber Risk & Incident Monitoring Lab (SMB SOC)

A hands-on lab to simulate how a Cybersecurity Risk Analyst/SOC analyst monitors, detects, triages, and reports security incidents in a small-to-medium business.

This project focuses on:
- Practical monitoring (SIEM + endpoint + network telemetry)
- Incident triage and response workflow
- Risk assessments + risk register
- Clear business-facing reporting (executive summary)

## Goals
- Build a realistic SMB security monitoring stack using open-source tooling
- Simulate attacks and validate detections
- Produce analyst-style deliverables: risk register, incident report, executive summary

## Tech Stack 
- Wazuh 
- ElK Stack
- Sysmon (Windows telemetry)
- Suricata or Zeek (network telemetry)
- Python (log enrichment + IOC checks)
- MITRE ATT&CK mapping

## Deliverables
- `docs/risk-register-template.md`
- `docs/incident-report-template.md`
- `ROADMAP.md` (week-by-week plan)
- Dashboards + alert evidence (screenshots)
- One full incident case study
