# Phase 2 — Monitoring Architecture

## Components
- Wazuh Manager (Ubuntu VM)
- Wazuh Agent (Windows Host)
- Sysmon for process visibility
- Kali Linux for attack simulation

## Monitoring Focus
- Authentication events
- Process creation
- File modification
- User account creation
- Suspicious command execution

## Objective
Gain visibility into endpoint behavior and simulate SOC detection capability.
